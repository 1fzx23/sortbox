sortbox
零依赖命令行文件整理工具 · 一个命令收拾干净你的下载文件夹
难度 L2 Python 标准库 跨平台 MIT License

它解决什么问题

下载目录里图片、文档、压缩包、代码搅成一团？手动分拣费时又容易出错。 sortbox 用一条命令把文件按扩展名或修改日期自动归类到子目录， 支持预览、回退脚本和安全重名处理——不依赖任何第三方库。

核心特性

🗂️

按扩展名分类

图片/文档/代码/压缩包/音视频/其他，自动分目录。

📅

按日期分类

按修改时间归入 YYYY-MM 月目录。

👀

dry-run 预览

先看清会动哪些文件，再决定是否执行。

↩️

undo 回退

一键生成反向 mv 脚本，手滑也能救。

🔒

安全重名

目标存在时自动加 _1 序号，绝不静默覆盖。

🔁

递归整理

连子目录里的文件一起收拾。

快速上手

# 预览（不改动任何文件）
python sortbox.py ~/Downloads --dry-run

# 真正整理到原目录下的分类子文件夹
python sortbox.py ~/Downloads

# 整理到指定目录 + 生成回退脚本
python sortbox.py ~/Downloads --target ~/Sorted --undo undo.sh

# 按修改日期归类 / 递归处理
python sortbox.py ~/Photos --mode date
python sortbox.py ./mess --recursive

命令参数

参数说明
path要整理的目录，默认当前目录 .
-t/--target分类目标根目录（默认与源目录相同）
-r/--recursive递归处理子目录中的文件
-m/--modeext（按扩展名，默认）或 date（按修改日期）
--map自定义分类映射 JSON 文件
-n/--dry-run只预览，不真正移动文件
-u/--undo执行后写出回退脚本到该路径
-l/--log把执行动作追加写入日志文件

工作原理

① 扫描：列出目录（或递归）下所有文件，跳过目录与隐藏文件。
② 分类：扩展名查映射表 → 分类目录；或读 mtime → YYYY-MM。
③ 规划：计算目标路径，目标已存在则自动加 _1 序号避免覆盖。
④ 执行：建目录并移动；可同时写出反向 mv 脚本以便回退。
